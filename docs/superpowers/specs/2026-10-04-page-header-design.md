# Единый паттерн оформления страниц (PageHeader) — Design Document

Дата: 2026-10-04
Статус: Approved

## 1. Проблема

Страницы UI оформлены несогласованно:

| Паттерн | Страницы |
|---|---|
| Заголовок вне карточки + карточки ниже | Каталог, Команды, Элемент (градиентная шапка) |
| Заголовок внутри общей Paper | Категории, Пак, API-токены, Избранное, Загрузка |
| Без заголовка страницы, контент с лишним верхним отступом | Инструкция |

## 2. Решение

Единый паттерн страницы (по модели Каталог/Команды — паттерн двух самых посещаемых страниц):

1. **Новый компонент `PageHeader`** (`ui/src/components/PageHeader.tsx`):
   - props: `title: string`, `subtitle?: string`;
   - рендер: `Typography variant="h4" component="h1"` (+ `mb: 0.5`), subtitle — `Typography color="text.secondary"`;
   - компонент возвращает `Box` (первый элемент `Stack spacing={3}` страницы).
2. **Скелет каждой страницы-списка**: `<Stack spacing={3}>` → `<PageHeader …/>` → карточки `Paper sx={{ p: 3 }}`.
3. **Перевод на паттерн** (заголовок выносится из карточки наружу): `AdminCategoriesPage`, `PackPage`, `TokensPage`, `FavoritesPage`, `UploadPage`. Внутренние заголовки секций карточек остаются (h6 с иконкой).
4. **GuidePage**: `PageHeader title="Инструкция"` + markdown без собственного `h1` (`# Инструкция` удаляется из `user-guide.md`, остальные уровни сдвигать не нужно — `h2` маппится как раньше). Убирается `mt: 4` у первого заголовка — верхний отступ выравнивается с другими страницами.
5. **CatalogPage, TeamsPage** — уже соответствуют паттерну; переводятся на `PageHeader` (заголовок + subtitle) для единых отступов/семантики.
6. **ElementPage** — осознанное исключение: градиентная шапка карточки элемента остаётся (hero конкретного объекта).

## 3. Тестирование

- `PageHeader.test.tsx`: рендерит h1 с title, subtitle опционален.
- Существующие тесты страниц не должны сломаться: заголовки остаются теми же текстами (проверить, что ассерты не привязаны к вложенности в Paper — используемые тесты ищут по тексту/роли).
- `GuidePage.test.tsx`: заголовок «Инструкция» по-прежнему `level: 1` — теперь это PageHeader.

## 4. Out of scope

- Рестайлинг карточек, отступов внутри Paper.
- ElementPage (градиентная шапка остаётся).
