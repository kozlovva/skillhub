# Страница инструкции для пользователя (Guide) — Design Document

Дата: 2026-10-04
Статус: Approved

## 1. Обзор

Отдельная страница в веб-UI SkillHub с инструкцией для конечного пользователя: как установить скиллы, как искать, как публиковать, как получить API-токен. Страница видна всем — включая неавторизованных сотрудников до входа через SSO.

### Ключевые решения

| Решение | Выбор |
|---|---|
| Содержание | Полный гайд: быстрый старт (CLI install), скачивание zip, поиск, публикация (UI + CLI), API-токены, FAQ |
| Хранение текста | Markdown-файл в репозитории UI, рендер `react-markdown` + `remark-gfm` |
| Видимость | Пункт навигации «Инструкция» для всех, роут `/guide` |
| Команды в тексте | Обобщённые, адрес хаба — плейсхолдер (без хардкода URL) |

## 2. Архитектура

- Роут `/guide` → `ui/src/pages/GuidePage.tsx`; регистрируется в `ui/src/App.tsx` внутри `AppLayout`.
- Пункт «Инструкция» добавляется в `navItems` в `ui/src/layout/AppLayout.tsx` (общий массив — виден всем, вне условий authenticated/isAdmin).
- Контент: `ui/src/content/user-guide.md`, импорт в `GuidePage.tsx` через Vite `?raw` — файл бандлится с приложением, версионируется с репозиторием, обращений к сети нет.
- Рендер markdown: `react-markdown` + `remark-gfm` (таблицы, списки задач). Маппинг элементов на MUI через `components`-проп:
  - `h1`–`h3` → `Typography` (variant h4/h5/h6)
  - `p` → `Typography` (body1, paragraph)
  - `code` (inline) → инлайн `Box` с моно-шрифтом и мягким фоном
  - `pre` → `Paper`-подобный блок: моно-шрифт, фон `#23272d`-стиль из темы, горизонтальный скролл
  - `a` → MUI `Link` (component RouterLink для внутренних ссылок не требуется — ссылки только внешние/анкоры)
  - `table` → стилизованная таблица (рамки, зебра через тему)
- Тема light/dark подхватывается автоматически из `theme.ts`/`ThemeModeProvider` — никаких жёстких цветов, только значения из темы.

## 3. Содержание гайда (разделы user-guide.md)

1. **Что такое SkillHub** — 2–3 предложения: корпоративное хранилище скиллов, скриптов и агентов для AI-агентов и людей.
2. **Быстрый старт: установка скиллов**
   - `npm i -g @skillhub/cli` (или разовый запуск через `npx @skillhub/cli`)
   - `skillhub login --url <адрес хаба>` (токен из веб-UI)
   - `skillhub install <slug>@<version|latest>` — установка в `.opencode/skills/` или `.claude/skills/` (авто-детект), `skillhub.lock` в корне проекта
   - Альтернатива без CLI: страница элемента → выбрать версию → «Скачать» (zip)
3. **Поиск** — каталог (поиск, фильтры по типу/сортировке), `skillhub search <query>`.
4. **Публикация**
   - Через веб: кнопка «Загрузить элемент» → страница `/upload` (включая manifest-инструкции, которые уже выведены на этой странице)
   - Через CLI: `skillhub publish <dir>` с `manifest.json` (name, version, description, type, changelog)
   - API-токены: страница «API-токены» (`/tokens`), создать токен, вставить в `skillhub login`
5. **FAQ**
   - Где взять токен? → `/tokens`, нужна авторизация через SSO
   - Куда ставятся скиллы? → `.opencode/skills/` / `.claude/skills/`, управляется `--target`
   - Как обновить версию? → `skillhub install <slug>@<новая версия>` (или `--force`)
   - Что делать при ошибке 401/нет токена? → `skillhub login`, проверить `SKILLHUB_TOKEN`

## 4. Обработка ошибок

Собственной логики с ошибками нет (статический контент). Markdown, который не парсится, просто отобразится как текст — приемлемо; секции гайда проверяются тестом на наличие ключевых заголовков.

## 5. Тестирование

- `GuidePage.test.tsx`:
  - рендерится заголовок страницы и ключевые заголовки разделов (Быстрый старт / Публикация / FAQ);
  - присутствуют примеры команд (`skillhub install`, `skillhub publish`);
  - markdown-контент реально рендерится (не сырой текст с `?raw`).
- `AppLayout.test.tsx`: пункт «Инструкция» присутствует в навигации для неавторизованного пользователя, ссылка ведёт на `/guide`.

## 6. Зависимости

Новые npm-зависимости UI: `react-markdown`, `remark-gfm`. Других изменений бэкенда/API нет.

## 7. Out of scope

- Редактирование гайда из админки (контент меняется коммитом в репозиторий).
- Версионирование гайда, i18n.
- Ссылки с автоподстановкой реального адреса хаба в команды.
