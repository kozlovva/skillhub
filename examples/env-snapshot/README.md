# Environment Snapshot

PowerShell-скрипт для быстрого снимка окружения разработчика: версии инструментов,
переменные окружения проекта, свободное место. Элемент типа **SCRIPT** —
не скилл с инструкцией, а самодостаточная утилита.

## Usage

```powershell
.\scripts\env-snapshot.ps1              # краткий отчёт в консоль
.\scripts\env-snapshot.ps1 -Full        # + все переменные окружения
.\scripts\env-snapshot.ps1 -OutFile env.txt
```

## Когда использовать

- «Какая у тебя версия Java/Node/Docker?» — не надо вспоминать, прогони скрипт
- Сбор информации перед repro бага: приложите снапшот к тикету
- Проверка, что CI-агент и локальная машина настроены одинаково

## Требования

- Windows PowerShell 5.1 или новее (работает и в PowerShell 7+)
- Права администратора не нужны
